# 财务思维

视野：资本、资源、成本、效率、风险
信息的使用，做分析、预测、资金管理、现金流管理、应收账管理、存货管理、投融资

财务思维：
* 收入、利润、现金流、应收账款 --> 某一项决策
* 看趋势 --> 多种决策

快速看透一家企业：
1、行业 --> 毛利率（40-50%比较不错）
2、规模 --> 收入
3、盈利能力 --> 利润
4、效率
5、资产-资产质量（应收账款、存活、现金「现金红线」）
6、风险-资金风险（未来缺那么多钱，先别做这件事）
7、企业文化：提前到/观察、看员工相处、下班时间看公司、卫生间

薪资拆分：月薪、奖金「怎么算才能拿到、基本拿多少」、期权
