**补充**：
完全二叉树：尽量填满的二叉树，除最后一层不一定满，必须左对齐，不能有空
满二叉树：每个节点，要么有2个节点，要么没有子节点

**为什么我们构建堆的时候，要从 n/2 - 1 这个位置开始，而不是从最后一个节点 n - 1 开始？**
构建大顶堆时，我们是从 n/2 - 1 开始向前调整的。 因为在完全二叉树的结构中，只有下标小于等于 n/2 - 1 的节点才可能有孩子，才有可能违反堆的性质。 而下标大于 n/2 - 1 的节点都是叶子节点，无需调整。 这是构建堆的关键优化点，也是保证构建时间复杂度为 O(n) 的重要原因。

## 逻辑
* 步骤拆解与时间计算
初始化大根堆（容量为 k）先取前 k 个元素构建大根堆，建堆时间为 O(k)（建堆的时间复杂度为线性，与元素数量成正比）。

* 遍历剩余 N - k 个元素对每个元素：
若元素小于堆顶（当前堆中最大的元素），则替换堆顶，并执行一次 “向下调整”（堆化），使堆重新满足大根堆特性。
若元素大于等于堆顶，直接跳过。
每次调整的时间复杂度为 O(log k)（堆的高度为 log k，k 是堆的容量），共需处理 N - k 个元素，因此这一步的时间复杂度为 O((N - k) log k)。
总时间复杂度
将两步相加：O (k) + O ((N - k) log k) ≈ O (N log k)（当 N 远大于 k 时，k 可忽略，主导项为 (N - k) log k）。


## 大根堆
* 父节点 ≥ 左右子节点，若根节点小于左右子节点，则交换左右子节点中较大的一个节点，与第一个非叶子节点(n / 2 - 1)交换位置，直至剩余最后一个元素。
* 堆顶是最大值，每次取的堆顶（最大值）被放到了末尾，后取的值（较小值）会排在前面，最终结果 = 从小到小排列（升序）
* 场景：从 400 万个数中选出 10 个最小的数字

时间复杂度：O (N log k)
```java
import java.util.*;

public class Top10SmallestNumbers {
    public static void main(String[] args) {
        // 生成400万个随机数作为测试数据
        List<Integer> numbers = generateRandomNumbers(4_000_000);
        
        // 找出10个最小的数
        List<Integer> top10Smallest = findTop10Smallest(numbers);
        
        // 输出结果（按从小到大排序）
        System.out.println("400万个数中的10个最小数（从小到大）：");
        Collections.sort(top10Smallest);
        for (int num : top10Smallest) {
            System.out.println(num);
        }
    }
    
    /**
     * 生成指定数量的随机数
     */
    private static List<Integer> generateRandomNumbers(int count) {
        List<Integer> numbers = new ArrayList<>(count);
        Random random = new Random();
        for (int i = 0; i < count; i++) {
            // 生成1到1亿之间的随机数
            numbers.add(random.nextInt(100_000_000) + 1);
        }
        return numbers;
    }
    
    /**
     * 使用大根堆找出最小的10个数
     */
    private static List<Integer> findTop10Smallest(List<Integer> numbers) {
        // 创建大根堆（通过比较器反转默认顺序）
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(10, Collections.reverseOrder());
        
        for (int num : numbers) {
            if (maxHeap.size() < 10) {
                // 堆中元素不足10个，直接加入
                maxHeap.add(num);
            } else {
                // 堆中已有10个元素，比较当前数与堆顶（当前最大的候选数）
                if (num < maxHeap.peek()) {
                    // 当前数更小，替换堆顶元素
                    maxHeap.poll();
                    maxHeap.add(num);
                }
            }
        }
        
        // 将堆中的元素转换为列表并返回
        return new ArrayList<>(maxHeap);
    }
}
    
```

## 小根堆
* 父节点 ≤ 子节点，若根节点大于左右子节点，则交换左右子节点中较小的一个节点
* 堆顶是最小值，每次取的堆顶（最小值）被放到了末尾，后取的值（较大值）会排在前面，最终结果 = 从大到小排列（降序）
* 场景：从 400 万个数中选出 10 个最大的数字
```java
import java.util.*;
import java.io.*;

public class Top10LargestNumbers {
    public static void main(String[] args) {
        // 生成400万个随机数作为示例数据
        List<Integer> largeNumbers = generateRandomNumbers(4_000_000);
        
        // 找出10个最大的数
        List<Integer> top10 = findTop10Largest(largeNumbers);
        
        // 输出结果
        System.out.println("400万个数中的10个最大数（从大到小）：");
        for (int num : top10) {
            System.out.println(num);
        }
    }
    
    /**
     * 生成指定数量的随机数
     */
    private static List<Integer> generateRandomNumbers(int count) {
        List<Integer> numbers = new ArrayList<>(count);
        Random random = new Random();
        for (int i = 0; i < count; i++) {
            // 生成1到1亿之间的随机数
            numbers.add(random.nextInt(100_000_000) + 1);
        }
        return numbers;
    }
    
    /**
     * 使用小根堆找出最大的10个数
     */
    private static List<Integer> findTop10Largest(List<Integer> numbers) {
        // 优先队列默认是小根堆，初始容量设为10
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(10);
        
        for (int num : numbers) {
            if (minHeap.size() < 10) {
                // 堆中元素不足10个，直接加入
                minHeap.add(num);
            } else {
                // 堆中已有10个元素，比较当前数与堆顶（最小的候选数）
                if (num > minHeap.peek()) {
                    // 当前数更大，替换堆顶元素
                    minHeap.poll();
                    minHeap.add(num);
                }
            }
        }
        
        // 将堆中的元素转换为从大到小的列表
        List<Integer> top10 = new ArrayList<>(minHeap);
        Collections.sort(top10, Collections.reverseOrder());
        
        return top10;
    }
}
```

## 堆排序思路
1、构建堆（建堆）
2、交换堆顶和末尾元素
3、缩小堆的范围（堆大小 -1）
4、重新调整堆（堆化 heapify）
5、递归重复2-4直到排序完成
