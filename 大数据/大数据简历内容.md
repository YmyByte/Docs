# 大数据简历内容
```markdown
**Technical Skills**  
- **大数据计算引擎**  
  - **Hadoop**: 精通 HDFS 分布式存储架构，熟悉 MapReduce 编程模型（InputFormat/OutputFormat 优化），具备大规模离线数据处理经验。  
  - **Spark**: 深入理解 RDD 弹性分布式数据集原理，掌握宽依赖/窄依赖优化、缓存策略（persist/cache）及共享变量（Broadcast/Accumulator）应用。  
  - **Flink**: 熟悉 Flink 流批一体架构，掌握 Checkpoint 容错机制、状态管理（Keyed State/Operator State）、窗口计算（Tumbling/Sliding/Session）。  

- **性能调优 & 数据倾斜处理**  
  - **Hive 优化**: 精通数据倾斜解决方案（Salting 分桶、Map Join、Skew Join 优化），熟悉分区裁剪、列式存储（ORC/Parquet）及动态分区策略。  
  - **Spark 优化**: 掌握 Join 策略选择（Broadcast Join/Sort-Merge Join）、内存调优（Executor 堆外内存配置）、Shuffle 优化（Tungsten 排序、自定义分区器）。  
  - **Flink 优化**: 熟悉反压机制（Backpressure）监控与调优，掌握状态 TTL 配置、Watermark 生成策略及 Checkpoint 调优。  

- **数据存储与查询**  
  - 熟悉 HDFS 分布式文件系统（副本机制、机架感知），掌握 Hive 元数据管理及 SQL 优化（谓词下推、列裁剪）。  
  - 了解 HBase 分布式 NoSQL 存储（RowKey 设计、LSM 树结构），熟悉 Kafka 分布式消息队列（Exactly-Once 语义）。  

- **工具链 & 生态**  
  - 工作流调度：Apache Airflow、Oozie  
  - 监控工具：Prometheus + Grafana（Spark/Flink 指标监控）  
  - 开发语言：Scala/Python（PySpark）、SQL、Shell  
```
**性能调优**
* Hive​​：增加 ​​Salting 分桶​​（解决数据倾斜）、​​动态分区​​（减少小文件）等具体方案。
* ​​Spark​​：强调 ​​Broadcast Join​​（避免 Shuffle）、​​Tungsten 排序​​（减少磁盘 I/O）等底层优化手段。
* Flink​​：补充 ​​反压机制​​（Backpressure）和 ​​Watermark​​ 等流处理关键点。
​​
**项目经验**  
- **电商实时风控系统**（Flink + Kafka）  
  - 设计基于 Flink 的实时反欺诈模型，通过 **状态 TTL** 和 **Watermark 对齐** 解决事件乱序问题，延迟降低至 200ms。  
  - 利用 **反压监控** 调整并行度，集群资源利用率提升 40%。  

- **用户画像离线分析**（Spark + Hive）  
  - 重构 Hive ETL 作业，通过 **Salting 分桶** 解决用户 ID 倾斜问题，查询性能提升 50%。  
  - 使用 Spark RDD 的 **广播变量** 减少 Join 操作数据传输量，任务耗时减少 60%。
