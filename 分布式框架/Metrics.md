# Metrics
* 定义与基本概念
    * Metrics 即指标，是对系统、应用程序或业务流程等方面的量化描述。它可以是各种数据，如系统的 CPU 使用率、内存占用、网络流量，应用程序的请求响应时间、吞吐量，业务流程中的订单处理量、用户活跃度等。通过收集和分析这些指标数据，能够了解系统或业务的运行状况。
* 常见类型
    * 系统指标：包括 CPU、内存、磁盘 I/O、网络等硬件资源的使用情况指标。例如，CPU 使用率可以反映系统的计算能力是否充足；内存的空闲和使用量能帮助判断系统是否存在内存泄漏或内存不足的问题。
    * 应用指标：针对具体应用程序的性能指标，如 Web 应用的每秒请求数（QPS）、平均响应时间、错误率等。这些指标能直接反映应用的性能和用户体验，帮助开发人员定位应用中的性能瓶颈。
    * 业务指标：与业务逻辑相关的指标，如电商平台的订单成交量、销售额、用户注册量、转化率等。业务指标是衡量业务发展和运营效果的关键数据，能为业务决策提供依据。
* 作用与应用场景
    * 性能监控：通过实时收集和展示 Metrics 数据，运维人员可以监控系统和应用的性能状态，及时发现性能问题，如响应时间过长、资源利用率过高等，以便及时采取优化措施。
    * 故障诊断：当系统出现故障时，Metrics 数据可以帮助快速定位问题所在。例如，通过分析 CPU、内存等指标的变化趋势，结合应用的日志信息，判断是由于资源耗尽导致的故障，还是应用程序内部的逻辑错误。
    * 容量规划：根据 Metrics 数据对系统的未来负载进行预测，从而合理规划系统资源，确定是否需要增加服务器、存储等资源，以满足业务增长的需求。
